# 07 — Агент headless: цикл, reconnect, принятие claim

**Требования:** R04 (агент), R04.2, R04.4, R11 (код+тесты)
**Blocked by:** 06 (machines API и политики)
**Зона:** `client/lib/agent.mjs` (новое), `client/main.mjs` (EDESK_AGENT wiring), `client/test/`
**Волна:** 3
**Status:** ready

## Что должно заработать

Тот же клиент работает как агент-служба: без окна, сам регистрируется
onboarding-кодом, держит связь (heartbeat + бесконечный reconnect с backoff),
принимает claim оператора по политике сервера (причина/PIN проверены сервером),
переживает обрывы по грейсу ADR 0013.

## Из брифа, дословно

> «Ещё и unattended» · «на живых пока не пробуем сначала пишем код который тестим»

## Разделы спецификации

Истории 23–24, 28; Решения §агент; Границы (`client/lib/agent.mjs`); Швы §2.

## Критерии приёмки

- [ ] `createAgent({api, signal, native, policy})` → `{start, stop, status}`; цикл: onboarding-код → machine token (хранится в userData, только память) → WS-коннект host-роли → heartbeat
- [ ] Обрыв: экспоненциальный backoff (с потолком), повторная аутентификация тем же токеном; грейс-состояния не оставляют зажатых клавиш (end() при разрыве)
- [ ] `EDESK_AGENT=1`: окно не создаётся, tray-иконка/логи честные; single-instance не мешает агенту и клиенту одновременно (агент — отдельный профиль userData)
- [ ] Интеграционные тесты на шве §2: регистрация по коду, reconnect, отказ при отозванном токене, heartbeat; инертные адаптеры
- [ ] `npm test` зелёный, lint чист; живая приёмка службы — MANUAL-QA (Windows приоритет)
