# 02 — i18n: словари ru/en, без строк в коде

**Требования:** R08, R14i, R01 (конвенции стека), R09 (тексты из эталона)
**Blocked by:** —
**Зона:** `client/lib/i18n.mjs`, `locales/`, `client/renderer/` (строки), `server/pages.mjs` + `server/app.mjs` (язык страниц), `client/test/`
**Волна:** 1
**Status:** ready

## Что должно заработать

Интерфейс клиента, браузерных страниц и страниц сервера существует на русском
и английском; язык выбирается по системе (клиент) / по `Accept-Language`+
настройке (сервер), переключается в настройках; в коде UI нет строк-литералов.

## Из брифа, дословно

> «да пока так» — языки ru + en · «удобный и красивый»

## Разделы спецификации

Истории 7–9; Решения §i18n; Швы §3.

## Критерии приёмки

- [ ] `client/lib/i18n.mjs`: `t(key, vars)`, `setLocale`, `initLocale` (системная локаль, фолбэк en)
- [ ] `locales/ru.json`, `locales/en.json` — все строки renderer'а и серверных страниц; контракт-тест: ключи существуют в обоих языках, в UI-модулях нет непокрытых литералов (эвристика + список исключений)
- [ ] Переключатель языка в настройках клиента; выбор сохраняется в settings.json
- [ ] Серверные `/downloads` и `/invite` отдают язык по `Accept-Language` (en/ru), кириллица не ломает вёрстку
- [ ] `npm test` зелёный, lint чист; визуально (скриншот-смок) русская вёрстка не разъехалась
