# 04 — Визуал сайта по эталону

**Требования:** R02, R06, R08i, R09i, R10i
**Blocked by:** 02
**Зона:** `server/app.mjs`, `server/test/`
**Волна:** 2

## Что должно заработать

`/downloads` выглядит как reference/site.png; `/invite` в том же стиле; скачивание — поток с поддержкой Range.

## Критерии приёмки

- [ ] Шапка: логотип-иконка, «EnotDesk | Удалённая поддержка», справа «Помощь» (якорь к загрузкам) и «Оператор» (→ `/invite`)
- [ ] Hero: eyebrow, H1 «EnotDesk», подзаголовок, CTA «Скачать» (иконка загрузки) + вторичная «Как это работает» (иконка play), чипы «Безопасное соединение / Быстрое подключение / Без установки» (щит/молния/замок), маскот `/brand/mascot-site.png` (бабл и рукописная подпись уже в растре, не дублировать)
- [ ] Секция «Скачать для вашей системы»: три карточки с SVG-иконками Apple/Windows/Linux; активная — иконка, название, имя файла, размер (МБ), архитектура, кнопка «Скачать»; неактивная — «Скоро будет» без ссылки; состав карточек — из `distFiles()` (реальные артефакты)
- [ ] «Как это работает»: 4 карточки с номером-бейджем и иконкой, тексты по реальному сценарию (ссылка в чате → запуск → ID и пароль → подключение и завершение)
- [ ] Футер: `EnotDesk v<cfg.version>` + «С заботой о ваших задачах ♥»; версия фактическая
- [ ] `/brand/` allowlist расширен `mascot-site.png` (и `mascot-app.png`); traversal по-прежнему 400/404
- [ ] `GET /api/v1/downloads-files/:name`: `Content-Length`, `Accept-Ranges: bytes`, `Range` → 206 с корректным фрагментом, иначе 200; allowlist без изменений
- [ ] Страницы без CDN/шрифтов/JS, адаптив 360px+, focus-ring; тесты HTTP-шва: `/downloads` содержит hero-тексты/чипы/шаги/футер; `/brand/mascot-site.png` 200; Range-ответ 206 и совпадает с файлом; `npm test` зелёный
