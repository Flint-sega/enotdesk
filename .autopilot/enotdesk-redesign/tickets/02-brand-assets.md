# 02 — Маскот-ассеты и иконка приложения

**Требования:** R05, R06
**Blocked by:** нет
**Зона:** `assets/`, `scripts/make-mascot.mjs`, `scripts/make-icons.mjs`, `BRAND.md`
**Волна:** 1

## Что должно заработать

Из эталонов вырезаны растровые маскот-ассеты; из кропа маскота собраны `icon.png/.icns/.ico`; BRAND.md описывает палитру и типографику эталона.

## Критерии приёмки

- [ ] `scripts/make-mascot.mjs` (Electron `nativeImage`, без новых зависимостей): кроп из `.autopilot/enotdesk-redesign/reference/app.png` → `assets/mascot-app.png` (маскот с ноутбуком), из `site.png` → `assets/mascot-site.png`, квадратный кроп головы/плеч → `assets/icon-source.png`
- [ ] Каждый кроп фактически просмотрен (read image): маскот целиком, без обрезки ушей/лап, фон эталона не рвётся грубо; координаты подобраны и записаны в скрипте; повторный запуск воспроизводит файлы
- [ ] `scripts/make-icons.mjs` собирает из `icon-source.png`: `assets/icon.png` 1024×1024 (маскот на тёмном фоне бренда), `assets/icon.icns`, `assets/icon.ico`; icns/ico валидны (`file`, `sips`); визуально проверены (просмотр PNG; иконка читается в 32px)
- [ ] `assets/enot-icon.svg` не тронут (шапка/фавикон); `assets/enot-mascot.svg` остаётся
- [ ] BRAND.md обновлён по эталонам: фон `#070D17`, панели `#0F1A2C`, границы `#1C2C44`, акцент `#35E0C4`, текст `#EAF2FF`, вторичный `#8FA3BF`; масштаб типографики hero
- [ ] Ничего вне зоны; `npm test` не ломается
