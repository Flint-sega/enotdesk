# 08 — Службы агента на трёх ОС + доки агента

## Что должно заработать

Агент ставится как служба: Windows (sc.exe), Linux (systemd unit с хардненингом),
macOS (LaunchDaemon). Есть инструкция установки/удаления и чек-лист живой
приёмки с приоритетом Windows. Граница session 0 задокументирована честно.

## Из брифа, дословно

## Критерии приёмки

- [ ] `client/agent-service/windows.md` + `.bat`/ps1-фрагмент (sc.exe, автостарт, описание), `linux.md` + systemd unit (NoNewPrivileges, ProtectSystem — как у сервера), `macos.md` + LaunchDaemon plist
- [ ] `docs/AGENT.md`: установка/удаление/обновление на трёх ОС, где хранится токен машины, логи; ограничение session 0 — честно; шаги ручной приёмки
- [ ] `docs/MANUAL-QA.md`: чек-лист живой приёмки (attended + unattended), приоритет — Windows; пополняется фазами
- [ ] Конфиги проходят синтаксис-проверки, доступные в среде (bash -n, plist lint если доступен); живая установка — MANUAL-QA
