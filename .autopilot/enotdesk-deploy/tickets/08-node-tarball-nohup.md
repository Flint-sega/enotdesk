# 08 — Node через официальный tarball + устойчивый деплой (D01)

**Требования:** R20, R22 (через D01)
**Blocked by:** 05
**Зона:** `scripts/`, `docs/SERVER.md`
**Волна:** 2
**Причина:** фактическое развёртывание (D01) доказало: NodeSource-установка на тестовом сервере зависает на apt update (ubuntu-зеркала отвечают `Ign`), а tarball nodejs.org скачивается мгновенно. Синхронный ssh-деплой убивается таймаутом SSH.

## Что должно заработать

Установщик ставит Node 24 официальным tarball-ом без apt и проверяет SHA256; деплой переживает обрыв SSH: установка идёт на сервере под nohup, локальный скрипт опрашивает лог и health.

## Критерии приёмки

- [ ] `install-server.sh`: блок NodeSource заменён на tarball: `NODE_VERSION` (default 24.12.0, override через env), скачивание `node-v$VER-linux-x64.tar.xz` + `SHASUMS256.txt` с nodejs.org, проверка sha256 (`sha256sum -c` по строке), установка в `/opt/node-24`, симлинки `node/npm/npx` в `/usr/local/bin`; идемпотентность (если уже нужная версия — шаг пропускается); apt не используется вовсе
- [ ] `deploy-server.sh`: удалённый запуск через `nohup ... > /tmp/enotdesk-install/install.log 2>&1 &`, локальный опрос: каждые 5 c печатает последнюю строку лога; при успехе — health-проверки как раньше; при ошибке — tail лога в stderr и ненулевой код; секреты по-прежнему не в argv
- [ ] `docs/SERVER.md`: ручная установка Node описывает tarball (не NodeSource); примечание, что apt на некоторых серверах недоступен
- [ ] Проверено: `bash -n`; `--dry-run` без root → понятная ошибка; `node --check` не касается
- [ ] Фактический Ubuntu-прогон — приёмка оркестратора (таск 07)
