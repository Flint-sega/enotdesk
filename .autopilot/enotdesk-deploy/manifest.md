## Самобрифинг (полный автомат)

ASSUMPTION — принято за пользователя:
1. Тестовый сервер используется как есть: Ubuntu 24.04, root, порт 8080, UFW выключен. Хостинг клиентов/боевой режим не разворачиваем.
2. TLS: у сервера нет домена — включаем явный документированный тестовый HTTP-режим; в документации есть раздел TLS через Caddy + домен для боевого запуска. Публичный запуск без TLS владельцем не считается.
3. Креды для скриптов задаются именами переменных ENOT_DEPLOY_HOST/USER/PASSWORD; значения живут только в .env пользователя; в репозиторий не попадают.
4. Node 24 ставится официальным tarball-ом (nodejs.org, SHA256) в /opt/node-24; apt на сервере не требуется (D01). Версия приложения ставится в /opt/enotdesk с симлинком current; БД в /var/lib/enotdesk.
5. Обновление — атомарная замена релиза через symlink; удаление — --uninstall без потери БД, --purge-data отдельно.
6. Пользователь сам создаёт первого администратора командой bootstrap на сервере (пароль не должен проходить через агента).

Открытых продуктовых решений не осталось.
