# 05 — Карточка «Подключиться» из чата + webhooks в тред

**Требования:** R07, R07.1, R04 (замыкание)
**Blocked by:** 02, 04  **Зона:** `hub/join.mjs`, hub/app.mjs (маршруты), hub/web (кнопка+карточка), server/test (webhook приём — нет, hub/test), client/locales, hub/test
**Волна:** 3

## Что должно заработать
Оператор в чате жмёт «Подключиться» → hub генерирует одноразовый join-token (TTL 10 мин, привязка к треду) → карточка клиенту (кнопки протокол+скачать) → клиент (T04) репортит креды → hub авто-claim (bearer агента) → system-сообщение «Сеанс 123 создан/подключён»; session.started/ended (webhooks EnotDesk) падают в тред.

## Критерии приёмки
- [ ] join-токены: одноразовые, TTL, отсутствует/просрочен → честная ошибка репорта
- [ ] Авто-claim: hub→EnotDesk /claim с bearer агента из сессии (фейк-EnotDesk в тестах); отказ — честная строка в тред
- [ ] /hooks/enotdesk: HMAC-проверка (секрет из настроек), события session.started/ended → system-сообщения (связь по sessionId)
- [ ] Сквозной фейк-тест: агент жмёт → токен → фейк-клиент репортит → claim → system-сообщения
