# Спецификация: EnotDesk — клиентский апгрейд v2

## Задача

Я опубликовал EnotDesk (remote support) и жду живой приёмки на двух машинах.
Пока она не сделана, программа должна стать лучше для тех, кто будет ею
пользоваться: легче по размеру, проще в первом запуске, с полноценным
unattended-набором (терминал, инвентарь, машины с UI, сообщение на экран) и с
серьёзной безопасностью (2FA, webhooks). Хвосты из ревью — добить.

## Решение

Сборки худеют на мёртвом грузе koffi (1–2 МБ); видео само снижает качество на
плохой сети и восстанавливает. Клиент настраивается без ручного ввода: адрес
сервера вшит при сборке или кладётся файлом рядом с exe; первый запуск честно
показывает, что сервер доступен. Для unattended: страница машин в браузерном
операторе (инвентарь, PIN, отзыв), удалённый терминал (SYSTEM v1, политика
сеанса, аудит), сообщение на экран машины. Операторы включают TOTP-2FA.
Сервер отправляет webhooks о сеансах с HMAC-подписью.

## Решения по реализации

- **Срез koffi — декларативный**: files-исключения в electron-builder.yml
  (`!node_modules/koffi/src/**`, `!node_modules/koffi/vendor/**`,
  `!node_modules/koffi/doc/**`). Никаких afterPack-скриптов: koffi резолвится
  через asar.unpacked, рантайму нужны index.cjs + src/koffi + бинарник
  @koromix/koffi-<platform> — всё остаётся. Electron Framework (192 МБ) не
  трогаем — это пол веса. Альтернативы рассмотрены и отвергнуты:
  декомпозиция Framework (бинарь монолитен, выгода ~0, риск пакета),
  afterPack-скрипты (рассинхрон с files-конфигом).
- **Адаптивный битрейт — чистая функция** над уже собираемыми rtc-stats
  (loss%/rtt); ступени вниз при ≥5% потерь, вверх не чаще раза в 15 с.
  Применяется через существующий `sender.setParameters`.
- **Первый запуск**: резолв адреса — сохранённый в settings → файл
  `enotdesk-server.txt` рядом с exe → ENOT_BAKED_SERVER_URL (сборка) → дефолт
  127.0.0.1:8080. Экран показывает результат health-проверки; чип статуса — на
  главном экране.
- **Терминал**: DC-канал `term` поверх утверждённого сеанса (та же политика:
  причина+PIN проверены сервером при claim); открытие/закрытие в аудит
  (`term.open`/`term.close`); лимиты: 1 на машину, буфер вывода 512 КБ (кольцо),
  таймаут простоя 5 мин. Windows: powershell от службы (SYSTEM — честно);
  Linux: `sudo -u <console-user> bash`; macOS: `launchctl asuser` + zsh.
- **Toast**: Windows — `WTSSendMessageW` (wtsapi32 через koffi) в активную
  сессию; Linux/macOS — notify-send/osascript best-effort. Вызывается оператором
  со страницы машин.
- **TOTP**: собственный модуль (HMAC-SHA1, окно ±1, base32), тесты на
  RFC-векторах; секрет шифруется AES-256-GCM ключом `ENOT_SECRET_KEY`; логин
  требует код; 10 резервных кодов — хеши; QR otpauth:// в настройках.
- **UI машин использует существующий machines API** (предыдущий прогон):
  GET/POST /machines, DELETE /machines/:id, POST /machines/:id/pin
  (setPin/verifyPin — хеши), POST /machines/:id/revoke; группа — поле машины;
  инвентарь добавляется T-инвентарём. Новый серверный код для UI не пишется.
- **Webhooks**: settings таблица (url, secret, events), доставка отдельным
  асинхронным путём, ретраи 3× (1с/10с/60с), подпись
  `X-Enot-Signature: hex(HMAC-SHA256(secret, body))`.

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| `client/lib/adaptive-bitrate.mjs` | политика качества видео | `nextTarget({lossPct, rttMs}, current, lastChangeAt, now) → {target, changed}` | ступени, гистерезис |
| `client/lib/first-run.mjs` | резолв адреса сервера при первом запуске | `resolveServerUrl({saved, execPath}) → {url, source}` | чтение файла, парсинг, порядок |
| `client/lib/term.mjs` | PTY-шов терминала агента | `createTerm({shell, cols, rows}) → {write, onData, resize, kill}`; `spawnShellFor(platform)` | различия ОС, контекст запуска |
| `client/lib/notify.mjs` | toast на экран машины | `showToast(platform, text) → {ok, reason?}` | WTSSendMessage/notify-send/osascript |
| `server/webhooks.mjs` | события→доставка | `createWebhooks(db) → {emit(event, payload), configure(url, secret)}` | подпись HMAC, ретраи |
| `server/totp.mjs` | RFC 6238 + base32 + резервные коды | `generateSecret/verifyCode(secret, code, {now})/backupCodes` | крипто-детали |
| `server/app.mjs` (новые маршруты) | /machines/:id/inventory, /machines/:id/toast, /settings/webhooks, /auth/totp* | HTTP | валидация, RBAC |
| web `/machines` панель | UI машин | страница (admin) | переиспользование web/* |

**Швы для тестов**: существующие (createServer HTTP/WS; lib-шимы без Electron;
контракт-тесты renderer/web). Новый шов один: `createTerm` — проверяется с
фейк-PTY и фейковым spawn (реальные shells — MANUAL-QA).

## Вне рамок

| Требование | Почему не сейчас |
|---|---|
| Живая приёмка на машинах (R11 прошлых прогонов) | решение пользователя: MANUAL-QA после кода; чек-лист пополняется |
| Терминал от пользовательской сессии (CreateProcessAsUser) | хрупко на Windows; v1 — SYSTEM, честно |
| Окна доступа unattended, D3 запись сеансов, third-party i18n | отложены пользователем/планом |
| Смена рантайма ради веса | пол Electron документирован, Tauri — другой проект |

## Открытые места

Плейсхолдеров нет. ENOT_SECRET_KEY — пустое имя в `.env.example` (появится;
включение 2FA без него честно отказывает). Наружные действия — по явной команде
пользователя: push в GitHub и тег релиза v0.2.0 (сборка 3 ОС + артефакты).
