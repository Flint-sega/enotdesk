# Как читать эту папку

- `dashboard.html` — этапы, прогресс и время, автоматически читает `state.js`.
- `enotdesk/2026-09-11-brief.md` — исходные слова пользователя.
- `enotdesk/manifest.md` — требования и их состояние.
- `enotdesk/spec.md` — спецификация.
- `enotdesk/tickets/` — таски разработки.

Для возобновления скажите «продолжи автопилот». HTML-макет в корне не является приложением удалённого доступа.
