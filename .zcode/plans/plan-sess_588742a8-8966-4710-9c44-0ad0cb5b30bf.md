# Большой план доработки — 5 блоков, 15 пунктов

Всё — код + тесты + ревью, живые машины не трогаем. После каждого пункта `npm test` зелёный, коммит за логический кусок. Итог: ~145-150 тестов.

## Блок A — Сервер и безопасность

**A1. Per-login защита от брутфорса.** В `/auth/login` неудачная проверка пароля бьёт в лимитер `loginId` (5 неудач / 15 мин на логин); исчерпан — 429 даже для верного пароля, соседние логины не тронуты. Конфигурируемо через `opts.limits`. Тесты: исчерпание → 429, другой логин работает, per-IP не сломан, в аудите неудачи видны.

**A2. Смена пароля (сейчас её нет вообще).** `PATCH /auth/password {oldPassword, newPassword}` — только для себя, старый пароль обязателен, новый ≥8; все прочие токены пользователя отзываются (кроме текущего). Кнопка в UI оператора (рядом с «Выйти»). Тесты: неверный старый — 403, смена работает, старый токен умер, слабый пароль — 400.

**A3. Глобальный потолок живых сеансов.** `live.size >= maxSessions` (env `ENOT_MAX_SESSIONS`, дефолт 200) → WS-аутентификация закрывается 4005 `server-busy`, честная ошибка клиенту. Защита памяти на публичном сервере. Тест: cap=1 → второй участник не пускается, после завершения первого — пускается.

**A4. ETag/Last-Modified/304 у файлов сборок.** `ETag: "<sha12 размера+mtime>"`, `Last-Modified`; `If-None-Match` → 304. Качалки не перекачивают гигабайты. Тесты: первый 200 с ETag → повтор с If-None-Match — 304 без тела; изменение mtime меняет ETag.

**A5. Бэкап БД: флаг установщика + скрипт.** Новый `scripts/backup-db.mjs` — `VACUUM INTO` в `/var/lib/enotdesk/backups/enotdesk-<UTC>.db` (безопасно на живой БД, чистый node:sqlite без sqlite3-CLI), ретенция N последних дампов. `install-server.sh --backup` запускает его под пользователем сервиса; в `docs/SERVER.md` — раздел «Бэкап по расписанию (cron)». Тест на скрипт: создаёт файл-дамп, читается `openDb`, старые дампы выметаются.

## Блок B — Качество кода

**B6. ESLint + CI-обвязка.** eslint (pinned, flat config): `server/`+`scripts/` — node, `client/` — browser/electron, рекомендованные правила без стилистики. `npm run lint`; в CI — `npm run lint`, `npm audit --omit=dev || true` (не падает), `.github/dependabot.yml` (npm, еженедельно). Чиню все находки.

**B7. Разбивка `renderer/app.js` (~1250 строк) + анти-мёртвые-кнопки.** Делю на `dom.js`, `session-media.js` (RTC+каналы+ввод), `views/{client,operator,contacts,team,history,settings}.js`; `app.js` — точка сборки и роутер сигналов. Контракт-тест: (а) скан `$('...')` по всем `renderer/**/*.js`; (б) каждый `id="btn-*"` из HTML обязан упоминаться в JS — защита от мёртвых кнопок навсегда. Поведение не меняю — чистый рефакторинг. Делаю предпоследним.

## Блок C — Клиент

**C8. Один экземпляр приложения.** `requestSingleInstanceLock()`; без лока — выход; `second-instance` → фокус окна. Сообщение «одно окно — одна роль» переписываю без совета «запустите второе окно». (Ручной пункт, отмечаю в AGENTS.md.)

**C9. Баннер «доступна новая версия».** Чистый `client/lib/version-check.mjs`: `parseVersionFromFilename('EnotDesk-0.2.1-win-x64.zip' → '0.2.1')`, `isNewerVersion()` — тесты на парсинг/сравнение/мусор. Рендерер: при старте и после настроек смотрит публичный `/downloads` JSON, если на сервере сборка новее — баннер `#update-banner` «Доступна 0.2.1 — скачайте на странице загрузок». Сетевые ошибки — молча.

**C10. Пауза трансляции (приватность).** `client/lib/media-toggle.mjs`: `setVideoEnabled(stream, on)` (чистая, тесты с моком stream). Кнопка `#btn-pause-stream` у клиента: «Скрыть экран» ↔ «Показать снова», статус «Трансляция приостановлена»; сброс при завершении сеанса. Чёрный кадр у оператора — на живую приёмку.

**C11. UX-мелочи сессии.** (а) Таймер длительности сеанса у оператора в тулбаре (интервал, чистится в stopMedia). (б) Непрочитанные в чате: если оператор в другой боковой вкладке — счётчик «Чат (2)» на вкладке, сброс при открытии. (в) Контекстное меню (копировать/вставить) для текстовых полей через `Menu.buildFromTemplate` + `webContents.on('context-menu')` в main — без новых IPC.

**C12. Отправка файла drag&drop.** `drop`/`dragover` на зонах чата/файлов обеих сторон: файл из `dataTransfer` уходит в существующий `sendFile`-путь (хелпер принимает `{files}` — мокается в тесте), подсветка зоны при перетаскивании. Обычная кнопка остаётся.

## Блок D — Оператор и данные

**D13. Индикатор качества соединения.** Раз в 2с `pc.getStats()` → rtt и потери; чистый парсер `client/lib/rtc-stats.mjs` (`summarizeStats(report) → {rttMs, lossPct} | null`) с тестами на мок-репорт. В `remote-status`: «Подключено · 45 мс · 0%» — оператор видит деградацию сети клиента.

**D14. Экспорт истории и журнала в CSV.** Чистый `client/lib/csv.mjs` (`;`, BOM, экранирование по RFC 4180) + тесты. Кнопки `#history-csv`/`#audit-csv`: до 1000 записей постранично, Blob + скачивание. Сервер не меняется.

## Блок E — Документация и финал

**E15. Доки под актуальный продукт.** README: функции (чат/файлы/буфер/грейс/видео-UX), схемы «как это работает», скриншот перегенерировать смоком. BUILD.md — новые модули. AGENTS.md — состояние, счётчик тестов, новые lib-модули, ручные пункты (single instance, пауза, качество, чёрный кадр).
