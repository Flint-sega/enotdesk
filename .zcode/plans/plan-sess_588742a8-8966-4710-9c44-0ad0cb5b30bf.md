# Прогон «клиентский апгрейд v2» — 2 фазы, 11 тасков

Процесс прежний: код + тесты + ревью (2 ревьюера) + коммиты. Живая приёмка не трогаем — MANUAL-QA пополняется (приоритет Windows). Цель: тесты 200 → ~260, размер не растёт. Схема работы (сервер-диспетчер → прямой WebRTC/DataChannel) не меняется — фичи ложатся в неё.

## Фаза 1 — размер, первый запуск, видео, интеграции

**T1. A1 — срез мёртвого груза koffi.** В electron-builder.yml files-исключения: `!node_modules/koffi/src/**`, `!node_modules/koffi/vendor/**`, `!node_modules/koffi/doc/**` (рантайму нужны index.cjs + src/koffi + бинарник @koromix — остаются). Агрессивная хирургия Electron Framework (192 МБ) — НЕ делаем (твоё условие: рискованно → не делаем; выгода ~0). Ожидание: −1–2 МБ, пол честно документируется. Критерии: pack:mac + EDESK_SMOKE (koffi доступен, нативный ввод работает), тесты зелёные.

**T2. A3 — адаптивный битрейт.** `client/lib/adaptive-bitrate.mjs` — чистая функция: (loss%, rtt) → целевой битрейт, ступени 2500/1200/600 кбит/с, понижение при потерях ≥5%, восстановление не раньше 15 с (гистерезис). Интеграция в существующий quality-polling session-media. Юнит-тесты ступеней/гистерезиса/восстановления.

**T3. B2 — вшитый адрес сервера.** Build-time env `ENOT_BAKED_SERVER_URL` → попадает в сборку; первый запуск берёт его как предзаполненный адрес (обязательный экран настроек не открывается). Тест резолва: baked → сохранённый → дефолт.

**T4. B1 — файл-конфиг рядом с portable-exe.** Без сохранённой настройки клиент читает `enotdesk-server.txt` рядом с process.execPath (первая строка — адрес). docs/BUILD.md — рецепт «склей настроенный клиент» для self-hostера. Тесты парсера.

**T5. B3 — честный экран соединения.** Первый запуск: статус «Сервер доступен (v…)» / «Сервер недоступен — проверьте адрес» + кнопка «Проверить» (health уже есть); чип статуса сервера на главном экране. Контракт-тесты id/ключей.

**T6. D1 — webhooks.** Админ задаёт URL+secret; события session.started / session.ended / machine.claim.denied; POST с HMAC-SHA256 подписью (X-Enot-Signature), 3 ретрая с backoff, best-effort (не блокирует сеансы). Тесты: подпись, ретраи, фильтр событий; секрет не в логах.

## Фаза 2 — unattended-блок

**T7. C5 — инвентарь машин.** Агент в heartbeat отдаёт os/version/uptimeSec/свободное место (statfs, честно по платформам) → machines.inventory (JSON) → API → отображение. Тесты store/API.

**T8. C2 — админ-UI машин.** Страница `/machines` в веб-операторе (только admin): список+пагинация, группа, PIN set/clear, отзыв, инвентарь. Все строки — словари ru/en; контракт-тесты страницы (ключи, мёртвые кнопки).

**T9. C4 — сообщение на экран машины.** Windows: koffi wtsapi32 `WTSSendMessageW` в активную сессию (главный путь); Linux: notify-send от консольного пользователя (best-effort); macOS: osascript (best-effort). Триггер оператором из UI машин. Каждая ОС — честный статус; непокрытое — MANUAL-QA.

**T10. C1 — удалённый терминал (v1 от службы/SYSTEM).** DC-канал `term` (allowlist имён дополняется): открытие требует той же политики, что claim (причина + PIN группы), открытие/закрытие — в аудит; лимиты: 1 терминал на машину, ограничение буфера вывода, таймаут простоя. Агент спавнит: Windows — powershell от службы (**SYSTEM, честная пометка** в доке и UI), Linux — bash от консольного пользователя (best-effort), macOS — zsh (best-effort). Минимальный терминал в веб-операторе (без xterm-библиотеки). Тесты шва: фейк-PTY, лимиты, политика.

**T11. D2 — TOTP 2FA.** Модуль `server/totp.mjs` (RFC 6238 HMAC-SHA1, окно ±1, base32) + тесты на RFC-векторах; users.totp_secret, шифрование AES-256-GCM ключом `ENOT_SECRET_KEY` (ключ не задан → включение 2FA честно отказывает с подсказкой); включение/выключение в настройках оператора (с текущим паролем); логин: пароль + код; 10 одноразовых резервных кодов (хеши); QR otpauth:// при включении. UI-поле кода в логине (desktop+браузер). Тесты полного пути.

## Финал

**T12. Приёмка фаз.** Тесты ≥260 зелёные, lint чист, smoke; ADR 0019–0022 (терминал SYSTEM v1, TOTP+шифрование, adaptive bitrate, webhooks+first-run конфиг); MANUAL-QA: терминал/toast/инвентарь на живых ОС; README/AGENTS.md обновление. Пуш и релиз v0.2.0 — по явной команде (наружное действие).

## Осознанно НЕ делаем

- Хирургия Electron Framework (A2) — пол 192 МБ, выгода ~0, риск пакета.
- D3 запись сеансов — дорого и чувствительно.
- Терминал от пользовательской сессии — Windows-хитрость, отложено.
- Окна доступа unattended, третьи языки, тикет-интеграции — отложено.
- Из concerns финала: переключатель языка серверных страниц, admin-баннер обновлений — собраны, триаж в конце прогона.
