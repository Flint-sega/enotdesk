# Видео-спайк ADR 0027 (только Windows)

Бенчмарк DXGI Desktop Duplication: меряет FPS захвата в нативном разрешении,
время маппинга кадра, время/размер JPEG-кодирования через WIC, CPU-долю процесса.
Двигает курсор на 2 px, чтобы рабочий стол обновлялся. Пишет один кадр в %TEMP%\enot-spike-frame.jpg.

Запуск: `cargo run --release` (нужен Windows 8.1+, тулчейн MSVC).
Критерий выхода спайка: >= 24 FPS @ 1600x900, CPU <= 15% одного ядра (см. docs/adr/0027).
