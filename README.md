# EnotDesk

Тёмный portable-клиент удалённой поддержки для Windows, macOS и Linux.

## MVP

- клиент запускает программу без установки;
- приложение показывает одноразовый ID и пароль;
- доступ действителен только во время работы клиента;
- оператор подключается, выполняет настройку и завершает сессию;
- после выхода клиента credentials инвалидируются;
- будущий control-plane: чат, операторы, роли, адресная книга и аудит.

## Лицензия и основа

Планируемая техническая основа — RustDesk (AGPLv3). При форке необходимо сохранить лицензии, уведомления об изменениях и предоставить исходный код изменённой версии согласно AGPLv3. Торговые марки и ассеты RustDesk не используются в брендинге EnotDesk.

## Безопасность MVP

ID и пароль должны генерироваться криптографически безопасно, пароль нельзя сохранять после завершения процесса, а сервер должен отклонять просроченные или повторно использованные credentials. Подключение разрешается только после явного запуска клиентом.

## Следующий шаг

Подключить исходный RustDesk в отдельной ветке и заменить UI/ресурсы, не меняя транспорт удалённого доступа до появления тестов.
