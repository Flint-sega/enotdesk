# Если что-то не так

Сначала найдите свой случай в таблице. Не помогло — соберите журналы (раздел 2) и напишите нам
(раздел 3).

## 1. Частые случаи

| Что видно | Почему так бывает | Что сделать |
|---|---|---|
| Клиент: «Сервер недоступен» | Неверный адрес сервера, нет интернета, сервер выключен | Настройки → адрес сервера (уточните у специалиста) → «Сохранить и проверить». Адрес `http://` работает только с галочкой «Разрешить HTTP» и только для тестового сервера. |
| Клиент: «Эта версия EnotDesk устарела для вашего сервера» | Администратор задал минимальную версию | Скачайте новую версию со страницы загрузок сервера. |
| Windows: окно брандмауэра при подключении | Программа без установки каждый раз новая для Windows | Можно нажать «Отмена» — связь работает. |
| Оператор видит «Ожидаем экран клиента…» или чёрный экран | Клиент ещё не нажал «Разрешить»; на Mac нет разрешения «Запись экрана»; на Linux сеанс Wayland без захвата | Клиенту: «Разрешить»; на Mac — Системные настройки → Конфиденциальность и безопасность → «Запись экрана», затем перезапустить EnotDesk. |
| Долго «Подключаемся…», когда стороны в разных сетях | Видео не может пройти напрямую и через ретранслятор | Администратору: открыть порты TURN (`3478` tcp/udp и `49160–49999` udp) и проверить coturn — [SERVER.md §9](../SERVER.md). |
| Мышь и клавиатура не действуют | Mac без «Универсального доступа»; Linux на Wayland; включено «Только смотреть» или управление у коллеги | Mac — выдать «Универсальный доступ»; Linux — войти в сеанс X11; в сеансе — «Взять управление». |
| Windows: окна «от администратора» и запрос UAC не управляются из программы без установки | Ограничение Windows: обычная программа не управляет окнами с правами администратора | Попросите человека нажать самому; для постоянной поддержки — служба ([постоянный доступ](unattended.md)). |
| Машина «офлайн» | Служба остановлена, компьютер выключен или без сети, машина отозвана | На компьютере проверьте службу (раздел 2); в «Машинах» — нет ли отметки «отозвана». Выключенный компьютер с Wake-on-LAN можно «Разбудить». |
| Mac: после обновления снова спрашивает разрешения | Сборка без подписи Apple — для macOS это «новая» программа | Выдайте разрешения ещё раз. |
| «Сессия панели истекла — войдите заново» | Вход в программу оператора истёк | Войдите снова; при «Запомнить меня» в приложении это делается само. |
| Потерян телефон с 2FA | — | Войдите резервным кодом; если их нет — администратор сервера снимает 2FA командой `reset-2fa` ([руководство администратора](server-admin.md#7-если-потерян-доступ)). |

## 2. Где журналы

Журналы не содержат паролей, токенов и одноразовых кодов — они маскируются при записи. Перед отправкой
всё же просмотрите их и при желании замените адреса и имена.

**Программа помощи (клиент):**

| ОС | Файл |
|---|---|
| Windows | `%APPDATA%\EnotDesk\enotdesk-boot.log` (вставьте путь в адресную строку Проводника) |
| macOS | `~/Library/Application Support/EnotDesk/enotdesk-boot.log` |
| Linux | `~/.config/enotdesk/enotdesk-boot.log` |

**Служба постоянного доступа:**

| ОС | Где смотреть |
|---|---|
| Windows | `C:\Windows\System32\config\systemprofile\AppData\Roaming\EnotDesk\agent\enotdesk-boot.log` (запуск агента), `C:\ProgramData\EnotDesk\enotdesk-video.log` (экран и ввод; папку `C:\ProgramData\EnotDesk` открывает только администратор), состояние: `sc query EnotDeskAgent`. Подробная диагностика службы: от администратора создайте пустой файл `C:\ProgramData\EnotDesk\svc-diag.enabled`, перезапустите службу — появится `svc-diag.log` (потом файл-маркер удалите). |
| Linux | `journalctl -u enotdesk-agent -n 200 --no-pager`, `systemctl status enotdesk-agent` |
| macOS | `~/Library/Logs/enotdesk-agent.log`, `launchctl print gui/$(id -u)/com.enotdesk.agent` |

**Сервер:** `journalctl -u enotdesk -n 200 --no-pager`; TURN — `journalctl -u coturn -b`.
**Программа оператора в браузере:** консоль разработчика (F12 → Console) — ошибки красным.

## 3. Как сообщить о проблеме

Откройте [новое issue на GitHub](https://github.com/Flint-sega/enotdesk/issues/new/choose) → «Сообщить
о проблеме» и заполните форму: версии (клиент — внизу окна, «EnotDesk vX.Y.Z»; сервер — поле `version` на `https://<сервер>/api/v1/health`), ОС, что делали,
что ожидали, что получилось, журналы из раздела 2.

Уязвимости безопасности не публикуйте в issue — сообщите закрыто через
[GitHub Security Advisories](https://github.com/Flint-sega/enotdesk/security/advisories/new) (см. [SECURITY.md](../../SECURITY.md)).
