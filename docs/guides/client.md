# Как получить помощь (для того, кому помогают)

Специалист подключается к вашему экрану только с вашего согласия и только пока открыта программа.
Закрыли окно EnotDesk — доступ закончился сразу и полностью.

## 1. Скачать и запустить

Ссылку на страницу загрузок даёт ваш специалист (обычно `https://<сервер поддержки>/downloads`).

| Компьютер | Что скачать | Первый запуск |
|---|---|---|
| Windows 10/11 | `EnotDesk-win-x64.exe` (без установки) | Если Windows пишет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае». Может появиться окно брандмауэра — можно нажать «Отмена», связь всё равно работает. |
| Mac с процессором Apple (M1 и новее), macOS 13+ | `EnotDesk-mac-arm64.dmg` (или `.zip`) | macOS 15 и новее: при первом открытии «Готово», затем «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Всё равно открыть». macOS 13–14: правая кнопка по EnotDesk → «Открыть» → «Открыть». |
| Linux (x86_64) | `EnotDesk-<версия>-linux-x86_64.AppImage` | Свойства файла → «Разрешить запуск как программы» (или `chmod +x` в терминале) и запустить. |

Программа не подписана покупным сертификатом — поэтому система и предупреждает. Скачивайте её только
по ссылке своего специалиста.

**При первом запуске** программа может спросить адрес сервера — его тоже даёт специалист. Если адрес уже
вшит в сборку, этого вопроса не будет.

**На Mac** один раз разрешите в «Системные настройки» → «Конфиденциальность и безопасность»:
- **«Запись экрана»** — без неё специалист не увидит экран;
- **«Универсальный доступ»** — без него специалист сможет только смотреть, но не управлять.

**На Linux** управление работает в сеансе X11. В сеансе Wayland специалист увидит экран, но управлять
не сможет — программа скажет об этом прямо.

## 2. Получить помощь

1. Нажмите **«Получить помощь»**. Через пару секунд появятся **Идентификатор** и **Пароль**.
2. Передайте их специалисту — в чате, письмом или по телефону. Кнопка «Копировать ID и пароль» копирует оба сразу.
   Пароль действует один раз, до конца этого сеанса.
3. Когда специалист подключится, появится окно **«Запрос на подключение»** с его именем: он просит видеть
   экран, управлять мышью и клавиатурой и передавать файлы. Нажмите **«Разрешить»**, если это тот, кого
   вы ждёте, иначе — **«Отклонить»**.
4. Если экранов несколько, выберите, какой показать.

## 3. Во время сеанса

- Вверху видно, кто подключён. Если подключился ещё один специалист, программа покажет его имя.
- **«Скрыть экран»** — специалист перестаёт видеть экран (например, чтобы ввести пароль). «Показать снова» — вернуть.
- **«Сменить экран»** — показать другой монитор или окно.
- Чат, **«Отправить файл»**, **«Синхронизировать буфер обмена»** — для переписки и обмена файлами. Файл от
  специалиста начнёт передаваться, только когда вы нажмёте **«Принять»**; «Отклонить» — отказаться.
- Если специалист 30 минут ничего не делает, программа предупредит и через минуту сама закроет сеанс.
- Если на короткое время пропал интернет (до 30 секунд), сеанс продолжится сам, разрешать заново не нужно.

## 4. Завершить

Нажмите **«Завершить сеанс»** или просто закройте окно EnotDesk. Ввод от специалиста прекращается сразу.
Для следующей помощи нажмите «Получить помощь» снова — будут новые ID и пароль.

Программа ничего не устанавливает и не запускается сама при включении компьютера (если вы не ставили
отдельно «постоянный доступ» — см. [руководство по постоянному доступу](unattended.md)).

## 5. Обновления

- Windows без установки и Mac: при выходе новой версии программа покажет сообщение — скачайте новую
  версию по той же ссылке.
- Установленная Windows-версия и Linux: обновление скачается само и установится после вашего
  подтверждения, никогда посреди сеанса.

Что-то не получается — [«Если что-то не так»](troubleshooting.md).
