# Постоянный доступ: подключение к компьютеру без человека рядом

Постоянный доступ — служба EnotDesk на компьютере, которая держит связь с вашим сервером. Оператор
подключается к такой машине с обязательной причиной (и PIN, если задан); каждое подключение записывается
в журнал, а человек за компьютером видит сообщение, кто подключился и зачем.

Ставьте службу только на компьютеры, которые вы обслуживаете с согласия их владельцев.

## 1. Создать машину (администратор)

1. Откройте программу оператора (`https://<сервер>/operator`) → **«Машины»** → **«Добавить машину»**.
2. Введите название (так машину увидят операторы) и, если нужно, группу → **«Создать и получить код»**.
3. Появятся **код машины** и **адрес сервера**. Код одноразовый, действует 24 часа и **больше не
   покажется** — сразу перенесите его на компьютер (щелчок по коду выделяет его целиком). Потеряли код —
   удалите машину и создайте заново.

## 2. Поставить службу на компьютер

### Windows 10/11 (основной путь)

1. Запустите EnotDesk на этом компьютере (без установки или установленный — всё равно).
2. **Настройки** → проверьте **адрес сервера** (тот, что показан рядом с кодом) → **«Сохранить и проверить»**.
3. Блок **«Машина (постоянный доступ)»** → вставьте код → **«Установить службу»** → в окне Windows
   «Разрешить этому приложению вносить изменения?» нажмите **«Да»** (нужны права администратора).
4. Программа сама скачает установщик той же версии, сверит его контрольную сумму, поставит EnotDesk в
   `Program Files` и службу **EnotDeskAgent** (запуск при загрузке Windows, автоперезапуск при сбое).
   Код хранится только до первой регистрации и затем стирается.
5. Через минуту машина в списке станет **«онлайн»**.

Ручная установка скриптами (`windows-install.bat`) — [client/agent-service/windows.md](../../client/agent-service/windows.md).

### Linux (Debian/Ubuntu)

1. Распакуйте AppImage в `/opt/enotdesk-agent/EnotDesk` (команды — в
   [client/agent-service/linux.md](../../client/agent-service/linux.md)).
2. Сохраните код в файл, например `/root/code.txt`, и запустите установщик из `client/agent-service/`:

```bash
sudo SERVER_URL="https://<сервер>" APP_DIR="/opt/enotdesk-agent/EnotDesk" \
     AGENT_NAME="<название>" AGENT_CODE_FILE=/root/code.txt ./install-linux.sh
```

Скрипт создаст служебного пользователя, зарегистрирует машину по коду (файл кода потом удалит) и
запустит службу `enotdesk-agent`. Без графического сеанса (сервер, NAS) служба работает в безэкранном
режиме: онлайн, терминал, сообщения, файлы — да, экран и управление — нет. Для экрана и управления нужен
сеанс X11 и `DISPLAY`/`XAUTHORITY` в `/etc/enotdesk-agent/agent.env`; на Wayland управление недоступно —
это сообщается прямо.

### macOS 13+ (Apple Silicon)

1. Перетащите EnotDesk в «Программы» и один раз откройте (см. [руководство клиента](client.md)).
2. Сохраните код в файл, например `~/code.txt`, и в Терминале, **без sudo**:

```bash
SERVER_URL="https://<сервер>" AGENT_NAME="<название>" AGENT_CODE_FILE=~/code.txt ./install-macos.sh
```

3. Разрешите EnotDesk «Запись экрана» и «Универсальный доступ» (Системные настройки → Конфиденциальность
   и безопасность).

Служба на Mac работает, пока пользователь вошёл в систему: экран входа macOS не поддерживается. Подробно —
[client/agent-service/macos.md](../../client/agent-service/macos.md).

## 3. Подключиться

«Машины» → нужная машина → **«Терминал»** → причина (+PIN) → «Подключиться». Что умеет сеанс машины и
кнопки строки — [руководство оператора](operator.md#3-постоянные-машины).

В сеансе машины: экран и управление (где доступны), терминал, сообщение на экран, файлы — в одну
сторону, в папку `EnotDesk Files` (Windows — `C:\Users\Public\EnotDesk Files`); чат — только от
оператора (показывается сообщением). Буфера обмена в сеансе машины нет.

## 4. Обновить, отозвать, удалить

- **Обновление.** Windows: установленная версия обновляется сама (служба переживает обновление).
  Linux и macOS: замените файлы программы и перезапустите службу — см. AGENT.md.
- **Отозвать** в «Машинах» — служба на компьютере больше не войдёт на сервер, даже если осталась.
  Чтобы вернуть — удалите машину и создайте новую с новым кодом.
- **Удалить службу с компьютера.** Windows: «Параметры» → «Приложения» → EnotDesk → «Удалить» (служба
  удаляется вместе с программой). Linux: `sudo ./remove-linux.sh`. macOS: `./remove-macos.sh`
  (`--purge-data` — вместе с профилем и токеном). Запись на сервере удаляется отдельно — «Удалить» в «Машинах».

## 5. Честные ограничения (сейчас)

- **Windows: экран блокировки, экран входа и окна UAC** через службу пока не показываются и не управляются —
  это в работе (ADR 0036) и войдёт после проверки на реальных компьютерах.
- **Windows: управление мышью и клавиатурой через службу** проверено на виртуальных машинах; проверка на
  реальном компьютере ещё идёт.
- **macOS:** только после входа пользователя. **Linux:** управление — только X11.
- Агент на Windows пишет журнал в `C:\ProgramData\EnotDesk\` (видео) — где искать остальные журналы,
  см. [«Если что-то не так»](troubleshooting.md).
