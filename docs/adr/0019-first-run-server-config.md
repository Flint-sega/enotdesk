# ADR 0019: первый запуск — вшитый адрес сервера, файл-конфиг рядом с exe, экран проверки; пол веса Electron Framework 192 МБ задокументирован

## Контекст

R03/R04/R05: self-hostер раздаёт клиент «своим» клиентам и не хочет, чтобы каждый вводил адрес сервера вручную; клиент при первом запуске должен честно показать, доступен сервер или нет. Дополнительно R01.1: часть веса сборки — мёртвый груз (исходники/доки koffi), но основной объём — Electron Framework, и нужно честно задокументировать, где пол. Замер: Electron Framework ~192 МБ — доминирующая часть артефакта.

## Решение

Резолв адреса сервера — фиксированный порядок: сохранённый в settings → `enotdesk-server.txt` рядом с exe → `ENOT_BAKED_SERVER_URL` (вшит при сборке через `extraMetadata`, с явным CLI-override) → дефолт `127.0.0.1:8080`. Функция `client/lib/first-run.mjs`: `resolveServerUrl({saved, execPath}) → {url, source}` — чистая, источник адреса виден в UI. Первый запуск показывает экран проверки соединения (результат health-запроса + кнопка «Проверить»), чип статуса живёт на главном экране. Срез мёртвого груза — только декларативные files-исключения в electron-builder.yml (`koffi/src`, `koffi/vendor`, `doc`); агрессивная хирургия Framework отвергнута.

## Почему

`${env:...}` в `extraMetadata` не раскрывается — доказано фактическим прогоном, поэтому вшивание делается подстановкой значения на этапе сборки, а не надеждой на подстановку переменных electron-builder'ом. Файл рядом с exe выбран против записи в системные пути: portable-сценарий остаётся переносимым, а источник адреса (`source`) можно показать пользователю. Экран проверки — против «тихого» фолбэка на дефолт: тихий фолбэк выглядит как успех и уводит клиента на localhost. Хирургия Framework (декомпозиция бинаря) — отвергнута: монолит, выгода ~0, риск сломать пакет; afterPack-скрипты — отвергнуты как рассинхрон с files-конфигом.

## Последствия

Клиент, собранный с `ENOT_BAKED_SERVER_URL`, работает без единого ручного ввода, но адрес остаётся перекрываемым: файл рядом с exe старше вшитого, сохранённый в settings — старше файла (порядок фиксирован, тестирован). `${env}` в `extraMetadata` считается неработающим — не использовать повторно. Пол веса — ~192 МБ Framework, задокументирован в BUILD.md: обещаний «в разы легче» нет, похудение дальше — только смена рантайма (ADR 0011, отдельный продукт). files-исключения koffi проверяются pack+smoke, а не `npm test`: срез задевает то, что в тестах не участвует.
