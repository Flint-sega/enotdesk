# ADR 0016: лицензия AGPL-3.0 вместо автостартовавшей GPL-3.0; self-host из коробки — docker compose (server+coturn+caddy) и bare-metal установщик с --no-turn/--no-tls; i18n собственным модулем без библиотек

## Контекст

R02/R03/R15i: проект публикуется в github.com/Flint-sega/enotdesk, и им пользуются чужие люди — self-hostер должен поднять сервер одной командой, не читая доков про Node; TURN и TLS разворачиваются сами (R13i/R16i); интерфейс — ru+en (R08/R14i). GitHub в пустом репозитории автостартом поставил GPL-3.0; до первого внешнего контрибьютора лицензию можно заменить без чужого согласия. Бюджета на управляемую инфраструктуру нет — всё должно работать на дешёвом VPS.

## Решение

Лицензия — AGPL-3.0 (файл LICENSE + ссылка в README), заменяет автостартовавшую GPL-3.0, пока в репозитории нет внешних контрибьюторов. Self-host — два пути из коробки: `docker compose up -d` (три сервиса: enotdesk с ENOT_* env и volume'ами `data/` и `dist/`, coturn с static-auth-secret из env, caddy с прокси на enotdesk:8080 и авто-Let's Encrypt по домену) и bare-metal `install-server.sh`, который сам ставит coturn и Caddy; `--no-turn`/`--no-tls` — явный отказ, dry-run показывает план. Без домена Caddy слушает :8080/http и пишет предупреждение в логи и на страницу — честный локальный режим, а не молчаливое «работает». i18n — собственный `client/lib/i18n.mjs` (`t(key, vars)`, `setLocale`, `initLocale`) + `locales/{ru,en}.json`; тот же словарь читают серверные страницы `/downloads` и `/invite` (по `Accept-Language` + настройке); язык по умолчанию — локаль системы, фолбэк en; ни одной строки-литерала в модулях UI (контракт-тест).

## Почему

Оставить GPL-3.0 — отвергнуто: она не закрывает облачный форк (кто-то поднимает EnotDesk как SaaS и не открывает свои правки); AGPL-3.0 закрывает ровно этот случай, а окно бесплатной замены закрывается первым внешним контрибьютором — поэтому решаться должно сейчас. Взять RustDesk Server целиком — отвергнуто пользователем: цель — свой код (R01); сравнение проведено, зафиксировано в brief «Дополнения». Писать свой TURN — отвергнуто: coturn — стандарт де-факто, свой релей повторял бы известное месяцами. Писать свой TLS-контур (certbot-скрипты, cron) — отвергнуто: Caddy получает сертификат сам, а без домена честно деградирует в http с предупреждением. i18n-библиотека (i18next и подобные) — отвергнуто: собственный модуль — порядка 40 строк, словари проверяются контрактом (ключи существуют в обоих языках), зависимость и её API не дают ничего нужного при двух языках.

## Последствия

AGPL-3.0 отпугнёт часть коммерческих пользователей — осознанная цена закрытия облачных форков; сменить лицензию позже без согласия всех контрибьюторов нельзя, обратной дороги нет. Compose — единственный поддерживаемый docker-путь: правки портов/volume'ов живут в `docker/`; volume'ы обязательны — пересоздание контейнеров не теряет БД и сборки, это проверяется, а не обещается. `--no-turn` означает: соединения за симметричным NAT могут не установиться — установщик предупреждает честно. Без домена HTTPS не появляется никогда — «http и работает» не выдаётся за полноценный режим. Собственный i18n: нет плюрализации, фолбэк-цепочек и платформы перевода — для ru+en достаточно; третий язык — новый словарь + правка контракта, но без crowdin-обвязки. Публикация (первый push, настройки репозитория) — наружное действие только по явной команде пользователя.
