# ADR 0006: portable без установки, автозапуска и служб; закрытие окна = полный выход

## Контекст

Клиент — неопытный пользователь, запускающий программу только на время сеанса по ссылке из чата. Три ОС. Бриф: «не устанавливается, просто запускается», доступ умирает вместе с процессом.

## Решение

Артефакты — portable (.exe, .app ZIP, AppImage) без инсталлятора, без службы, без автозапуска и дочерних input-демонов. Закрытие BrowserWindow завершает процесс: stop media, close PC/DataChannel, блокировка ввода, разрыв signaling — локально, не дожидаясь сервера. macOS: последнее окно закрывает приложение; никаких tray/hide-режимов.

## Почему

Рассмотрена модель «установленная служба + tray-приложение» (путь RustDesk): отвергнута — даёт незаметный фоновый доступ и требует прав администратора при установке, что противоречит базовому обещанию продукта «закрыл — доступа нет». Рассмотрен tray/hide с видимым значком: отвергнут — клиент-непрофессионал не отличит «свёрнуто» от «доступ закрыт», а честность индикации является ядром attended-модели; единственный явный выход — закрытие окна, которое невозможно перепутать.

## Последствия

UAC/secure desktop, экран входа в ОС и Wayland-управление недостижимы принципиально, а не «пока не сделаны» — это честно документируется. После каждого перезапуска ОС для новой помощи нужен клиент заново: никакой автоподъём. Сервер обязан доводить завершение сам (heartbeat/lease) — локальный клиент может умереть жёстко, не попрощавшись.
